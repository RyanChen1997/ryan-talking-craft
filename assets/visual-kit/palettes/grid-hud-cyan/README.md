# 网格 HUD 青

ID：`grid-hud-cyan@1`。黑底透视网格的默认配色。

- 舞台：dark；卡片：深 slate 玻璃；强调：Radix cyan11 `#4ccce6`，实心块可用 cyan9 `#00a2c7` 的白字配对。
- 兼容背景：`perspective-grid@1`。
- 适用：衣服或房间偏黑、灰、蓝、冷白；科技口播、HUD 信息卡。青是暖白网格线的互补色。
- 不适用：浅色背景；人物衣服或灯光大面积驼、棕、暖黄，且希望动画跟着暖起来。
- 来源：Radix Colors 暗色 slate + cyan；直播/口播 overlay 常用近黑 + 单一冷强调。不是现场取样 hex。

预览：`Palette-Compare`，palette=`grid-hud-cyan@1`。
