# 网格电影琥珀

ID：`grid-cinema-amber@1`。与暖白网格线、钨丝灯光同一色温。

- 舞台：dark；卡片：sand 玻璃；强调：Radix amber11 `#ffca16`。
- 兼容背景：`perspective-grid@1`。
- 适用：衣服或灯光明显偏驼、棕、暖黄；中文口播常用的黄字重点。
- 不适用：浅色背景；人物画面已经很冷、再加黄会脏。
- 约束：Radix 规定 amber 实心块配深色字。模板必须用 `onAccent`（`#16120c`），不要在琥珀底上写白字。
- 来源：Radix sand + amber。强调跟服装／灯光家族，不跟皮肤。

预览：`Palette-Compare`，palette=`grid-cinema-amber@1`。
