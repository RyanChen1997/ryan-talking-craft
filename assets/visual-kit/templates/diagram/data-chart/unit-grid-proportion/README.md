## ID

`unit-grid-proportion@1`

## 适用场景

比例型结论（"每 100 个 / 10 个人里有 N 个"）、转化率 / 留存率 / 成功率、社会统计与用户调研类口播；两组比例对比可左右各一个点阵。输入只有数据，卡自带矢量；人物不参与

## 动效描述

100 个小方格从网格中心分环长出（每环 4 帧 + ≤3 帧确定性抖动，1.1s 铺满；只做 opacity + scale .8→1，无位移），然后从左上起按阅读顺序逐格染成强调色（0.035s 一格），右侧 128px 大数字与染色同一时钟 0→37，图例最后浮出——把"37%"摊成 37 个可数的个体
