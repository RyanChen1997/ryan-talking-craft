# 媒体适配

用户录屏与辅助演示视频：保持全部源画面、原始宽高比，objectFit=contain；禁止 cover、空间 crop、zoom、数字推近、拉伸。可以完整等比缩小到布局区域。

时间剪辑是另一回事：允许源时间片段截取与忠实的独立片段重排。禁止通过重排伪造操作顺序或因果。

比例不匹配时允许有设计意图的留白／matte，不为消除空白裁掉视频。优先给录屏更大区域、缩小或隐藏人物、预留字幕。主口播人物 PIP 单独以人脸与手势安全约束裁切，不能套用到录屏上。

主口播 PIP 必须作为 `StageLayout.presenter` 渲染，不在外部另画人物框。人物媒体填满该槽；可在不切掉脸、手势和必要物体的前提下使用 cover，并保持静音。最终圆角来自布局槽的 `borderRadius` + `overflow: hidden`，不能仅给视频本身设置圆角，也不能依赖源视频四角恰好露出圆角。

截图是否允许局部展示取决于任务与真实性约束；不能将截图的聚焦模板套到受保护视频。分析 ROI 不进入成片。
