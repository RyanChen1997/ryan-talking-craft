# 低成本视频理解

先读字幕与元数据，后看图。真人口播主要检查人物位置、景别、手势；录屏定位操作阶段与结果；动效研究只加密已选中的短事件。

```bash
uv run --project <skill-dir> --no-dev python <skill-dir>/scripts/build_video_contact_sheets.py <videos...> --output-dir .cache/talking-craft --sample-count 12 --width 480
```

先向模型提交联系表，不默认逐张看原尺寸帧。默认最多 12 个等距候选帧、单帧长边 480；脚本使用 Pillow 生成带源秒数的联系表，无需 ImageMagick。按文件哈希与参数复用缓存，损坏或缺失缓存重新生成。

需要确认具体事件时使用 extract_frames.py 的 `--times 12.0,12.5,13.0`，单轮通常补 3～6 帧，并说明待回答的问题。读细小文字优先按需要裁切 ROI；分析 ROI 不是成片裁切许可。

粗采样不保证覆盖短暂动作；联系表不够清楚就标为未确认，不猜按钮文字。复杂长视频分时段处理，动态审美必须正常速度看完整事件。当前脚本尚未自动做镜头检测或相似帧去重，不能声称有这些能力。

图片文件体积不是 token 成本；记录提交数量、尺寸与实际可获取的 token 数据。参数上限只是防误用，不是质量保证。不把全部抽出的候选帧自动送给模型。
