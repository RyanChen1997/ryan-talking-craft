## ID

`word-slot-cycle@1`

## 适用场景

口播里"它能帮你 A / B / C / D"式的功能或用途列举、受众列举（学生 / 上班族 / 创作者 → 所有人）、章节预告（今天讲 选品 / 定价 / 投放）、反复句式（不是 X，不是 Y，是 Z）；4~6 个短语、末词是结论；比逐条列表快、比逐词淡入有节拍

## 动效描述

句干"一个 AI，帮你"左端锚死不动，句尾深色胶囊每 0.7s 向上翻一格换一个短语（前 8 帧换位 power2.inOut + 运动模糊、后 13 帧静置读词），胶囊宽度随词长帧内插值伸缩，胶囊外上下露两行 13% 的幽灵项暗示"还有一串"；换完 4 个词胶囊 0.23s 上飞逃走，结论"搞定所有事"从下 90px 带 back.out(1.4) 过冲落进同一位置——全卡唯一一次过冲留给结论，之后静置 ≥1.5s 再与句干同收
