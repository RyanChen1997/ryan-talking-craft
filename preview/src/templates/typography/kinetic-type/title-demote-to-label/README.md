## 适用场景

教程 / 方法论口播的小节交接（标题先当主角再让位给内容）、"第 N 点"结构（每点标题降格后留在左上角当路标直到下一点）、问答式（问题降格成标签、答案在下方展开）、与 chapter-progress-list 配合接进度条；内容 ≤4 条
