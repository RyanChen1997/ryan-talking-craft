## ID

`flying-words@1`

## 适用场景

名词科普片的开场底层（"这期讲的 22 个概念"）、片头片尾的"信息量"垫底、能力清单的动态背景（前景放人物或标题）、纵深穿越感的转场垫层；深底专用（白底整套失效）；一支片 ≤1 段

## 动效描述

深底上 22 个名词按黄金角铺在扁椭圆截面（半径 82~247）上，沿 z 轴从 −1750 匀速飞到 +800 穿过相机平面擦身而过，每词相位 i/N 均分、跑满 2 整圈首尾无缝；生命曲线 [0,1,.5,.2,0]——前 1/4 猛亮、中段压到半透给前景让位、末段拖尾消失；越近越往画外散（drift .5→1.85），冲到眼前（u>.86）加运动模糊；中心一枚静态光晕钉住"隧道尽头"。它是幕底级背景层，前景放人物或标题
