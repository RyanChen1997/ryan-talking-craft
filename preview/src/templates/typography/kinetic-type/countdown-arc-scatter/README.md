## ID

`countdown-arc-scatter@1`

## 适用场景

数字本身是悬念的标题——时长承诺（"5 分钟搭好创作系统"）、数量揭晓（"3 个原则"）、倒计时语义的开场、需要"仪表盘"语汇的短镜；数字先从一串候选里被"扫停"再落位，比数字直接落更有揭晓感

## 动效描述

一串相邻递减的数字 11 / 10 / 9 … 5 / 4 / 3 切向挂在半径 150 的弧上，整盘从 96° 扫回 0°（0.57s，power2.out 急停），位置角超 ±70° 的数字用角度算透明度"转进视野"；停稳那一刻被选中的"5"正在弧顶，随即 0.3s 平移到标题首字符位并同步回正，其余数字原地 blur 3 淡出不位移，"分钟 / 搭好 / 创作系统"逐词解糊，末词 1.75s 染强调色；落定后整幕静止到 4.6s 同收
