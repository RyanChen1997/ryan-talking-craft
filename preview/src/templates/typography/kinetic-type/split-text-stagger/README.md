## ID

`split-text-stagger@1`

## 适用场景

章节题 / 金句的利落入场、片名 / 频道名字卡、要点句逐条上台（每条一次）、与下划线类卡衔接（基线即下划线）；是 per-character-rise 的"裁切 + 基线"变体——要版式感（字被线裁着长出来）选它，要"一股气顶上来"的纯气势选 per-character-rise

## 动效描述

标题"把复杂的事，讲简单"9 个字各在自己的裁切盒（高 = 行高 78）里从下方 115% 升起、back.out(1.2) 带约 10% 过冲回落，字间错峰 2 帧（0.067s）、每字行程 0.5s；同时一条 3px 基线从左向右 scaleX 长到整行宽，生长时长 = 字的总错峰时长，长满与末字落定同帧——字像从一条线里长出来；1.4s 副标淡入，4.4s 整组同收
