## ID

`lead-word-zoom-assemble@1`

## 适用场景

一句话主张先让主语立住（"效率 才是唯一的护城河"）、产品名 / 人名 introducing 字卡、数字先行（"3 倍 的产出，同样的时间"）、反转句先亮否定词（"不是 → 不是不努力，是方向错了"）；金句 / 转折镜头的文字面，首词 ≤4 字

## 动效描述

首词"效率"以 2.3 倍字号独占画面正中、hold 0.4s 期间继续推近 6%；随后一条 power3.inOut 曲线同时完成"缩回终字号"（0.4s）与"整行左滑归位"（0.8s，同起同曲线时长两倍），后续词各自从槽位右侧 28px 被推进来（0.4s power4.out，淡入只 2 帧），结论词落位即强调色；整行落定后上移 28px、副行同一时窗浮出，静置 3s 后同收
