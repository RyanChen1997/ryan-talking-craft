## ID

`chip-grid-single-select@1`

## 适用场景

口播里"N 个方案 / 套餐 / 工具我选哪个 → 选了它之后会怎样"的决策 + 因果镜头；投票 / 调研结果揭晓；排除法收到最后一个。输入是纯文字，人物不参与

## 动效描述

N 个候选 chip 3+2 居中铺开让观众读题（前 2s）；选中帧先插 1 帧灰色按压，紧接 5 帧 linear 反黑（底→墨、字→白）+ 1→1.04→1 极轻正弦回弹，其余 chip 降到 18% 但位置锁死；停 1.5s 看清选中态后余项归零、黑 chip 上移 46px 收窄 0.82 并横向补偿回中线，下方算式行浮现逐词加深——"选了它，然后……"
